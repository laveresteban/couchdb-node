# CLAUDE.md — couchdb-node

TypeScript SDK, npm package `couchdb-node`. Mirrors couchdb-python.

- `couchdb_client/`: generated by `typescript-fetch`. Never edit; run
  `npm run generate:node` in couchdb-sdk-generator.
- `src/`: hand-written async wrapper (`client.ts`, `database.ts`,
  `changes.ts`, `errors.ts`).
- `conformance/step_impl/steps.ts`: Gauge steps (gauge-ts).
- Version comes from `couchdb_client/.generated-from`
  (`scripts/sync-version.mjs`, `--check` in CI and release).

## Commands

```sh
npm ci && npm run build && npm test
bash scripts/conformance.sh [--tags sync]
docker compose -f conformance/docker-compose.yml run --rm conformance
```

## Rules

- Write user docs verbatim (`verbatim()` override). The generated
  `Document` serializer adds/clobbers fields.
- Read responses with `.raw.json()` (the `json()` helper) for the same reason.

## Fixes still open

Done in 0.6.0/0.7.0: regenerated client, continuous feed, abortable `stop()`,
`sync.spec`, continuous and 0.7.0 conformance steps (46/46), `bulkSave` revs,
`get()` `revs`/`latest`, snake_case options, session re-login,
`replicationUrl`, `head`/ETag, maintenance and listing helpers.
`scripts/conformance.sh` now fails on skipped scenarios.

- `scripts/conformance.sh` runs `gauge install ts`, which needs network even
  when the plugin is already installed.
